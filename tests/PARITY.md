# Parity with the bash

The Python core (`skills/pstack-pair/scripts/pstack_core/`, `P` below) replaced the bash of `pair-core.sh` command by command. The parity suite
(`tests/test_pstack_core.py`) runs the bash at a base commit against the Python on shared fixtures and fake agents. This file says which base is the
oracle for what, and lists every difference from the bash that was accepted, with the test that pins it.

## The parity bases

| Base | Oracle for | In the tests |
| --- | --- | --- |
| d06a932 | phase 1: the helpers and the first ported commands | the original `bash()` harness against the tree it was cut from |
| e6e83e3 | phase 2: wait, finish, notify, report, next, queue, step, dispatch, discuss, the plan gates, `report_ready`, `steps_due`, `open_notes` | `base_skills()` extracts `skills/` at that commit; `DELETED_BASH` names the helpers whose bash is gone from HEAD, and `bash()` runs any snippet that names one against this tree, asserting the tree defines it |
| 04d2c13 | phase 3: init, permission, stop, steer, answer, spawn, rotate, failover, the pane helpers, `spawn_role`, the preflights, `stop_prime_role` | `phase3_skills()`; `phase3_ab()` and `leaf_both()` run a world through 04d2c13's script and the working tree's and compare stdout, stderr, status, the store, events.tsv rows and calls.log |
| b632713 | phase 4: kitchen.sh's own commands (catch, retro, new-handoff in unit 022; the rest as later units port them) | `phase4_skills()` extracts `skills/` at that commit (no `die` patch: the commit is after unit 006); `phase4_ab()` runs a world through b632713's `kitchen.sh` and the working tree's and compares stdout, stderr, status, the store, events.tsv rows and calls.log |

A test that drives deleted bash always reads it from one of these trees, never from HEAD, and a comparison is never replaced by a literal where a
base can still run.

## The D15 drive

What decided D15, as it ran (unit 012, on this host, against the fake herdr): the script below, run as `python3 d15.py` from the repository root (it uses `tests/test_pstack_core.py`'s `ab_world` for the store and the fake herdr; `time.sleep` in `wait_for` is a bounded poll of at most 10 s for the child's own child, then of `/proc/<pid>` for its end, not a test). It starts `bash -c 'pair.sh wait ...'` once per tree (`e6e83e3`'s `skills/` for the base, the working tree for the port), waits until the command sits inside its herdr call, `kill -9`s the outer shell, and polls whether the command's process is still there.

```python
import sys, unittest, subprocess, os, time, signal
sys.path.insert(0, '/home/br1anchen/Documents/open-pstack/tests')
import test_pstack_core as t
def kids(pid):
    return subprocess.run(['pgrep', '-P', str(pid)], capture_output=True, text=True).stdout.split()
def wait_for(fn, n=200):
    for _ in range(n):
        v = fn()
        if v: return v
        time.sleep(0.05)
class T(t.CoreTests):
    def runTest(self):
        for side in ('base', 'port'):
            tree = self.base_skills() if side == 'base' else t.root / 'skills'
            spec = dict(args=['wait', '{st}', '--timeout', '600000'], agents={'s1': 'working claude'}, pair={'sent': {'file': '{st}/briefs/001-x.md', 'kind': 'BRIEF', 'epoch': 1}})
            top, st, env, fill = self.ab_world(f'd15-{side}', spec)
            cmd = f'{tree}/pstack-pair/scripts/pair.sh wait {st} --timeout 600000; echo finished'
            proc = subprocess.Popen(['bash', '-c', cmd], cwd=top / 'repo', env=env, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
            child = int(wait_for(lambda: kids(proc.pid))[0])
            grand = wait_for(lambda: kids(child))
            print(side, 'command', child, open(f'/proc/{child}/cmdline').read().replace('\0', ' ')[:70], '| in herdr call:', bool(grand))
            os.kill(proc.pid, signal.SIGKILL); proc.wait()
            gone = wait_for(lambda: not os.path.exists(f'/proc/{child}') or open(f'/proc/{child}/stat').read().split()[2] == 'Z', 100)
            print(side, 'command', child, 'ended after kill -9 of its parent shell:', bool(gone))
            if not gone: os.kill(child, signal.SIGKILL)
unittest.TextTestRunner(stream=open('/dev/null', 'w')).run(T())
```
